# Operating-Systems
Operating Systems coursework from SCU. 

The content from this course is as follows:

Lab 1: Shell programming. Creating basic programming computing areas and perimeters of circle and rectangles.

Lab 2: C programming. Working with processes running concurrently. Using processes to execute commands such as ls.

Lab 3: Producer/Consumer. Shared memory. Using pipes to execute commands and solve the producer/consumer problem.

Lab 4: Using pthreads to create a program to compute matrix multiplication. One program creates a thread for each row and the other created a thread for each cell.

Lab 5: Using semaphores and mutex locks to solve the producer/consumer problem.
